# Independent bundled adapter checks

This fixture consumes the versioned Knapshots artifact from Maven. It checks ordinary Kotlin resolution and diagnostics, then checks a member generated by Knapshots' test compiler plugin. The driver builds a small Gradle integration and an IDE-compatible compiler artifact in a local test repository, configures KEFS, and launches the bundled adapter. KPaths is not required.

The fixture artifact uses a three-component version because KEFS matches compiler JARs using semantic version numbers. The test-only repository and artifacts are not published as part of Knapshots.
